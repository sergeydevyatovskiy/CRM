# Mini CRM Lead Card

Небольшое CRM-приложение для создания и хранения лидов.

Проект представляет собой веб-интерфейс для добавления клиентов с сохранением данных через Google Sheets API.

## Возможности

* создание нового лида;
* валидация обязательных полей;
* маска номера телефона;
* автоматическое добавление даты и времени создания;
* отображение лидов в виде карточек;
* сохранение данных после перезагрузки страницы;
* изменение этапа сделки;
* хранение данных в Google Sheets.

## Стек технологий

### Frontend

* HTML5
* CSS3
* JavaScript (Vanilla JS)

### Backend / Storage

* Google Apps Script
* Google Sheets

```
Browser
```

Google Apps Script выступает в роли простого API-слоя между клиентской частью и таблицей.

## Функциональность

### Создание лида

Пользователь может заполнить:

* имя клиента;

* телефон;

* источник:

  * Холодный;
  * Тёплый;

* ответственного:

  * Лидоруб;
  * МОП;

* этап сделки:

  * Новый лид;
  * Квалифицирован;
  * Назначена консультация;
  * Отказ;

* флаг "Запрошено ТЗ".

После сохранения:

* создаётся уникальный ID;
* фиксируется дата создания;
* данные отправляются в Google Sheets.

## Изменение этапа сделки

Реализована дополнительная функция изменения этапа.

Последовательность:

```
Новый лид
      ↓
Квалифицирован
      ↓
Назначена консультация
      ↓
Отказ
```

После изменения отправляется API-запрос на обновление записи.

## API

### Получение лидов

```
GET /exec
```

Возвращает список лидов в формате JSON.

### Создание лида

```
POST /exec
```

Пример запроса:

```json
{
  "action": "create",
  "lead": {
    "name": "Иван",
    "phone": "+7 (999) 123-45-67",
    "source": "Тёплый",
    "owner": "МОП",
    "stage": "Новый лид"
  }
}
```

### Обновление этапа

```
POST /exec
```

Пример:

```json
{
  "action": "update",
  "lead": {
    "id": "123",
    "stage": "Квалифицирован"
  }
}
```

## Запуск проекта

1. Клонировать репозиторий.

2. Открыть проект через локальный сервер.

Например:

* VS Code + Live Server.

3. В файле `script.js` указать URL Google Apps Script:

```javascript
const API_URL = "YOUR_GOOGLE_APPS_SCRIPT_URL";
```

4. Настроить Google Sheet:

Столбцы:

```
id
name
phone
source
owner
stage
tz
created
```

## Особенности реализации

* Используется Vanilla JavaScript без дополнительных библиотек.
* Google Sheets используется как простое хранилище данных.
* Google Apps Script реализует API-логику.
* Для повышения устойчивости предусмотрено резервное сохранение через localStorage.
