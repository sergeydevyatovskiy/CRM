МИНИ CRM — КАРТОЧКА ЛИДА

## Описание проекта

Реализована простая веб-страница для добавления и хранения лидов в CRM.

Функциональность:
* создание нового лида;
* заполнение данных клиента;
* сохранение информации;
* отображение добавленных лидов в виде карточек;
* сохранение данных после обновления страницы;
* изменение этапа сделки;
* хранение данных через Google Sheets API.

## Используемые технологии

Frontend:
* HTML5
* CSS3
* JavaScript

Хранение данных:
* Google Sheets
* Google Apps Script как API-слой

## Поля лида
Карточка содержит:
* имя клиента;
* номер телефона;
* источник лида:
  * Холодный;
  * Тёплый;
* ответственный:
  * Лидоруб;
  * МОП;
* этап сделки:
  * Новый лид;
  * Квалифицирован;
  * Назначена консультация;
  * Отказ;
* переключатель "Запрошено ТЗ";
* дата и время создания лида.

## Дополнительные возможности
Добавлено:
* маска номера телефона;
* автоматическая фиксация даты создания;
* уведомление об успешном сохранении;
* автоматическая очистка формы после сохранения;
* кнопка изменения этапа сделки;
* отправка данных через API-запрос.

## Описание API

Google Apps Script используется как простой backend.

Методы:

GET:
* получение списка сохранённых лидов.

POST:
* создание нового лида;
* обновление этапа сделки.

## Проверенные сценарии

Проверено:
1. Создание нового лида.
2. Проверка обязательных полей.
3. Вывод сообщения об ошибке.
4. Сохранение данных после обновления страницы.
5. Запись данных в Google Sheets.
6. Изменение этапа сделки.
